# Плашки инструментов

Скруглённые SVG-плашки с неоновым контуром. Изображения самостоятельны: без JavaScript, внешних шрифтов и запросов к сторонним серверам.

Значки сохранены из ранее использованных Shields.io / Simple Icons badges. Их источники — соответствующие исходные плашки Android Studio, GitHub, Figma, Kotlin, Jetpack Compose, n8n и Telegram. Контуры, оформление капсул и подписи подготовлены для этого профиля.
